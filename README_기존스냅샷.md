# 가전운송계획 — Streamlit 배차 비교 대시보드

작성일: 2026-09-16 / 표시시각: 한국 표준시(KST)

**이 패키지는 사이트로 배포할 수 있는 소스 코드입니다. 아직 공개 접속 주소를 발급하거나 실제 클라우드에 배포한 결과물은 아닙니다.**

## 가장 먼저: 예시 사이트 열기

1. ZIP 압축을 풉니다. GitHub에 새 저장소를 만들고 이 폴더 **안의 파일**을 올립니다. `app.py`와 `requirements.txt`가 저장소 최상위에 있어야 합니다. `.streamlit` 폴더도 포함합니다. 실제 엑셀·고객자료·차량자료·백업은 올리지 않습니다.
2. Streamlit Community Cloud에 로그인하고 GitHub 저장소를 연결합니다. `Create app`에서 저장소·브랜치를 선택하고 실행 파일을 `app.py`로 지정합니다. Python은 3.12를 선택합니다.
3. `Deploy`를 실행합니다. 설치·실행이 정상 종료되면 Streamlit에서 웹주소가 생성됩니다. 생성된 주소로 접속하면 **예시 전용 사이트**가 열립니다. 주소는 배포 후에 확정되며 이 문서의 주소 예시는 실제 사이트가 아닙니다.

기본 예시모드는 추가 DB·로그인 설정 없이 허구 데이터만 보여 줍니다. 실제 자료의 업로드는 차단되어 있습니다. 실제 자료로 시험하려면 먼저 아래 업무모드를 설정하거나 PC 테스트 모드를 사용합니다.

## 업무용 사이트로 전환하기

웹주소와 영구 데이터 저장은 별도입니다. 실자료를 사용하려면 회사가 승인한 호스팅·저장·인증 구성을 먼저 정하세요. Streamlit Cloud로 업로드하면 파일은 외부 앱 서버로 전송됩니다. 사내 반출 제한이 있다면 같은 코드를 사내 승인 서버에 배포해야 합니다.

### 필요한 관리자 설정

- **외부 PostgreSQL 데이터베이스:** `database_url`을 Secrets에 설정합니다. 애플리케이션은 `dispatch_records` 테이블을 생성하므로 초기에는 CREATE TABLE 권한이 필요합니다. 영구저장소를 운영하는 곳의 백업, 복구, 접근정책을 별도로 설정해야 합니다. 이 앱이 자동으로 DB 서비스를 개설하지는 않습니다.
- **로그인:** Google OIDC 예시가 준비되어 있습니다. 인증 공급자에서 OAuth/OIDC 클라이언트를 만들고 실제 앱 주소의 `/oauth2callback`을 리디렉션 URI로 등록합니다. 공급자가 `email` 및 `email_verified=true`를 제공해야 이 예시 권한 검사가 통과합니다. 다른 공급자는 클레임 설정/권한 검토가 필요합니다.
- **업무권한:** `.streamlit/secrets.example.toml`의 구조를 사용해 Cloud의 **App settings → Secrets**에 실제 값을 입력합니다. `mode="live"`, 승인 이메일 목록, 편집자 목록, DB 및 OIDC 값을 설정한 다음 재시작합니다. 실제 `secrets.toml`은 GitHub에 저장하지 않습니다.

**권한은 기본 차단 방식입니다.** 로그인하지 않거나 이메일 미승인·미검증 상태면 자료를 읽지 않습니다. 승인된 모든 이용자는 동일한 배차 데이터셋을 조회·내려받을 수 있고, `editors`에 들어간 이용자만 등록할 수 있습니다. 팀/고객사별 데이터 분리는 제공하지 않습니다. 원천 스냅샷의 작성자 표기와 별도로 실제 업로드 계정·UTC 등록시각·파일 SHA256을 기록합니다.

Community Cloud의 공개/비공개 기능은 배포 계정 화면과 당시 서비스 조건에서 별도 확인하세요. 이 앱은 호스팅 서비스의 비공개 옵션만을 업무 인증 수단으로 가정하지 않습니다.

## 기존 엑셀 양식 사용

앞서 제공된 `가전운송계획_대시보드_입력양식.xlsx`를 그대로 사용할 수 있습니다. **실자료 입력은 `스냅샷입력`과 `변경이력` 시트만 읽습니다.** 사용안내·참고차량·구역 등 다른 시트는 집계하지 않습니다. 표의 열 이름은 바꾸지 마세요. 날짜는 ISO 텍스트 또는 Excel 날짜값, 시각은 초 단위까지 입력합니다. 입력 데이터의 수식은 값 붙여넣기로 바꾸세요.

- CSV 입력양식은 `templates` 폴더와 사이트 자료 등록 메뉴에 있습니다.
- XLSX 두 시트는 함께 검증·저장하며, 어느 쪽이든 충돌하면 파일 전체를 반영하지 않습니다.
- 기존 HTML의 `dispatch-compare-v1` JSON 백업을 읽습니다. 예시로 표시된 JSON은 업무 데이터에 합치지 않습니다.
- 파일당 20MB, XLSX 압축해제 총량 100MB 제한입니다. 고객명·전화·주소를 넣을 필요가 없습니다.
- XLSB, 기존 삼성 시스템 임의 내보내기 파일의 자동 변환, 시스템 자동 로그인·수집은 포함하지 않습니다.

## 최초·최종 계산

운영일 × 차량번호별로 입력된 완료/최종확정 기록 중 가장 이른 시각을 최초로 잡습니다. 그 이후의 가장 늦은 기록을 최종으로 선택합니다. 마지막 상태가 최종확정이 아니면 미확정 표시를 붙입니다. 실제 최초인지 확인할 수 없는 자료는 시점근거를 `사후관측`으로 입력해야 합니다.

최초 기록만 있는 차량은 최종 0으로 처리하지 않고 `후속자료 없음`으로 표시합니다. KPI는 동일한 비교가능 차량 집합만 사용합니다. 전부 취소·반출되어 0건이 된 차량도 후속 0건 스냅샷을 반드시 저장하세요.

```
예상 최종 = 최초 − 연기 − 취소 − 반출 + 반입 + 추가 + 복원 − 배차해제
미설명 차이 = 실제 최종 − 예상 최종
```

이력은 `최초시각 < 변경시각 ≤ 최종시각`인 경우만 해당 차량에 반영합니다. 최초와 같은 초의 변경은 최초 현황에 포함되었다고 간주합니다. 원천에 초 미만 시각/변경순번이 있으면 사전 정합성 확인이 필요합니다. 차량마다 최초시각이 달라 전체 반출과 반입 합계는 다를 수 있습니다.

건수가 같아도 차량 이동·취소 후 복원이 있으면 변경차량입니다. 차이가 0이라고 이력 누락이 없음을 보증하지 않습니다. 연기는 다른 운영일로 빠지는 경우이며 같은 날 시간 조정은 차감하지 않습니다. 주문번호를 방문건수로 임의 환산하지 않습니다. 용적은 원본 단위를 유지합니다.

**이미 저장된 행은 덮어쓰지 않습니다.** 같은 키·같은 내용은 중복 제외, 다른 내용은 전체 등록 거부입니다. 더 이른 완료 자료가 나중에 추가되면 최초 기준시각이 앞당겨질 수 있지만, 과거 행 자체는 수정하지 않습니다. 정정·삭제 UI는 제공하지 않으며 관리자의 원천 확인과 백업 후 정정이 필요합니다.

## PC에서 테스트하기

Windows에서 Python 3.12를 설치한 뒤 `run_local.bat`을 실행합니다. 로컬 모드는 `127.0.0.1`로만 바인딩하고 `data/dispatch.db`에 저장합니다. 최초 패키지 설치에는 인터넷이 필요합니다. `data` 폴더를 지우면 로컬 데이터가 지워집니다.

이 모드는 로그인 없는 단일 PC 테스트용입니다. 인터넷·외부망에 공개하지 마세요. Community Cloud에서 `DISPATCH_LOCAL` 환경변수를 설정하지 마세요. 실제 업무용 서버에는 OIDC와 PostgreSQL 구성을 사용하세요.

예시만 PC에서 실행할 때:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.address=127.0.0.1
```

다른 담당자가 등록한 자료는 `저장자료 새로고침`으로 읽습니다. 자동 수집, 실시간 푸시, 백그라운드 갱신, 자동 백업 스케줄은 포함하지 않습니다. JSON 내보내기는 수동 백업입니다.

## 검증 범위

이 패키지 작성 시 **18개 자동 테스트 통과**, 기존 엑셀 입력양식의 빈 입력 시트 읽기 확인, Python 문법 검사 완료.

검증 항목: 최초/최종 비교, 후속자료 없는 차량, 기준시각, 차량별 상이한 최초시각, 연기·취소·복원, 왕복 이동, 중복 제외, 충돌 시 전체 롤백, CSV/JSON 호환, CSV 수식 삽입 방지, SQLite 재조회 및 감사기록.

**실제 Streamlit UI 실행·브라우저 렌더링·클라우드 배포·OIDC 로그인·외부 PostgreSQL 접속은 이 환경에서 검증하지 못했습니다.** 작성 환경의 패키지 설치 네트워크가 차단되어 Streamlit 실행까지 확인하지 못했습니다. 배포 후 예시화면, 승인/미승인 계정, 편집/조회권한, 재시작 후 데이터 유지, 백업·복원, 동시 등록을 확인한 뒤 실업무에 사용하세요.

```bash
python -m unittest test_core -v
```
